# figalign

論文のfigureを**実寸で**組む。

Pythonで描いたパネルをIllustratorで配置すると、データとの繋がりはそこで切れる。査読でデータの差し替えを求められると、配置の作業は丸ごと捨てることになる。figalign はこの往復を消す。

```
レイアウト宣言 → ソルバ → 各パネルの実寸(mm) → matplotlibが実寸で描画 → 無変換で貼る
```

後から拡縮しないので、パネル間でフォントサイズと線幅がずれない。

## インストール

```sh
git clone https://github.com/yuki-hada/figalign.git
cd figalign
pixi install
pixi run figalign example
# -> http://127.0.0.1:8765
```

pixi を推奨するのは、cairosvg が `libcairo` (Cライブラリ) を必要とし、pip がこれを供給できないため。conda-forge はこれをパッケージとして持つので、システムパッケージも root も不要でPDF出力が動く。計算クラスタではこれが効く。

既存の解析環境に入れる場合は pip か uv を使う。figalign はユーザーの `panels.py` を同一プロセスで実行するので、パネルが import するものが見える環境に入れる必要がある。

```sh
pip install -e .            # または: uv pip install -e .
pip install -e '.[pdf]'     # PDF出力用。別途システムの cairo が必要:
                            # macOS: brew install cairo / Debian: apt install libcairo2
```

cairo が無くても、合成PDF以外はすべて動く。プレビュー、SVG出力、ライブリロード、パネル単体のPDF (これは matplotlib 自身のPDFバックエンドを通る)。

## 実行

```sh
pixi run figalign example                   # ブラウザでプレビュー
pixi run figalign example -o figure.pdf     # 書き出して終了
pixi run figalign example -o figure.svg
```

データが計算サーバー上にある場合は、そちらでサーバーを起動して `ssh -L 8765:localhost:8765 <host>` でポート転送する。

## セキュリティ

HTTP API に到達できることは、そのままコードを実行できることを意味する。クライアントはプロジェクトに `.py` を書き、`fig.toml` にそれを指させられる。そのためサーバーはトークンを要求し (起動時にURLに含めて表示する)、`--allow-remote` を付けない限りループバック以外にはバインドしない。

共有マシンではループバックは私的ではない。同じノードにログインしている他のユーザーは 127.0.0.1 に到達できる。トークンはそこでも効く。他所からプレビューを見たい場合は、広くバインドするのではなくポートを転送する: `ssh -L 8765:localhost:8765 <host>`。

figure の描画はプロジェクトのPythonを実行する。`python panels.py` と同じことである。figalign はその前にディレクトリごとに一度確認し、答えを `~/.config/figalign/` に記録する。`--trust` は確認を省き、`--no-token` はトークン無しで動かす。

## figure の書き方

`fig.toml`:

```toml
preset = "nature_double"        # 図幅と文字スタイルはプリセットが持つ

grid = [["a", "a", "b"],        # mosaic文字列 "aab\ncdb" も可
        ["c", "d", "b"]]

row_heights = ["1fr", "0.7fr"]  # fr と mm は混在可。固定長を先に引く
gap = "4mm"

[panels.a]
fn = "panels.py:scatter_main"

[panels.c]
src = "schema.svg"              # 手描き素材をセルに流し込む
```

| キー | 既定 | 内容 |
|---|---|---|
| `preset` | `"default"` | `nature_single` / `nature_double` / `science_*` / `cell_*` / `default` |
| `grid` | 定義順に1行 | 2次元配列または mosaic 文字列。`"."` は空セル |
| `col_widths` `row_heights` | すべて `"1fr"` | `"1fr"` と `"25mm"` を混在可 |
| `gap` `gap_x` `gap_y` | `0` | 軸枠と軸枠の間隔 |
| `width` | プリセットの幅 | 総幅の上書き |
| `height` | 未指定 (`1fr` = 40mm) | 総高さ。指定すると fr が残りを按分する |
| `labels` | `true` | a, b, c... の自動採番 |
| `data` | あれば `panels.py:load_data` | データ層の入口 |

`panels.py`:

```python
def load_data():
    """重い読み込みはここ。ソースが変わるまで結果を保持する"""
    return ...

def scatter_main(ax, data, size):
    """figsize は外から注入される。ここで図のサイズを決めない"""
    ax.plot(data["x"], data["y"])
```

## 出力

| URL | 内容 |
|---|---|
| `/` | プレビュー |
| `/ws` | 監視対象ファイルの変更通知 |
| `/api/figure.svg` | grid に従って合成した最終SVG |
| `/api/figure.pdf` | 成果物。cairosvg で変換 |
| `/api/panel/{name}.svg` | パネル単体 (`?w=88mm&h=46mm`) |
| `/api/panel/{name}.pdf` | パネル単体のPDF (`pdf.fonttype = 42`) |
| `/api/stats` | 接続数と描画キャッシュのカウンタ |

SVG はテキストをテキストのまま保つので、軽く編集もできる。PDF は matplotlib 側で先にテキストをパス化するので、cairo が組み直すのではなくプレビューとグリフ単位で一致する。テキストのまま残すには `?text=keep` または `--keep-text` を渡す。

どちらも宣言した実寸のページで出る。

## 軸枠の整列

パネルを独立に描画すると軸枠が揃わない。枠の外側のマージンはほとんどが目盛りラベルで、その幅がパネルごとに違うからだ。figalign はセルではなく枠を解く。

1. 各パネルを一度描いて `ax.get_tightbbox()` と `ax.get_position()` の差を実測する
2. 同じ列の枠が同じ座標に来るように解く
3. `figsize` と `subplots_adjust` を厳密指定して本描画する

帰結が2つある。

- **`fr` が按分するのは枠であって、セルではない。** `1fr` の2列は目盛りラベルがどうであれ同じ枠幅になり、固定の `"30mm"` は「枠が30mm」を意味する。figure はその周りに育つので、総高さを固定したいなら `height` を指定する
- **`gap` は床である。** 枠と枠の距離であり、ラベルはその内側に住む。向かい合うマージンが `gap` より広い場所では、間隔がそれに合わせて広がる

## 画面

左がエディタ、右がプレビュー。境界はドラッグで動かせる。

`zoom` は `fit / 50% / 75% / 100% true size / 150% / 200%` で、既定は `fit`。実効パーセントは常に隣に表示され、100%を下回ると琥珀色になる。`fit` は縮小のみで拡大しない。78%表示で線の太さを判断してしまうとこのツールの意味が消えるため。

パネルのタブに切り替えると、そのパネルの軸枠が縁取られる。`check` はプレビューをグレースケールや1型/2型/3型色覚のシミュレーションに切り替える。「この2系列は色相しか違わない」を刷る前に気づくため。

## ブラウザ上での編集

コードの上にタブが並ぶ。`data`、パネルごとに1つ、最後に `layout`。同じファイルを指すタブは1つのバッファを共有する。エディタはCDNから読む CodeMirror で、LSPも補完も無い。CDNに届かない場合は素のテキストエリアに落ちる。

保存は ⌘S。書き込みがディスクに落ち、watcher が気づき、接続している全プレビューが再描画する。VS Code での編集と同じ経路。

- **書き込みは前提条件を持つ。** エディタは最後に読んだダイジェストを送る。ファイルが下で変わっていればサーバーは409を返し、バッファは保持される
- **パスは検証する。** `..`、絶対パス、プロジェクト外を指すシンボリックリンク、`.py` / `.toml` / `.svg` 以外は拒否する

`undo` は全文スナップショットを1つずつ遡る。スナップショットはサーバーのメモリ上にあり、再起動すると消える。

## ライブリロード

変更は、実際に無効化する層に対応付けられる。

| 層 | キー | 無効化される条件 |
|---|---|---|
| データ | `load_data` のソース + そのファイルのモジュールスコープのソース | そのローダーか共通コードの編集、コード以外のファイルの変更 |
| 描画 | パネル関数のソース + 確定サイズ + データのキー | そのパネル1つの編集、またはサイズの変化 |
| 合成 | キャッシュしない | 毎リクエスト。数msなので |

なので `fig.toml` の `labels` を触ってもパネルは1枚も再描画されず、パネル関数を1つ編集すればそのパネルだけが再描画され、`gap` を変えると全サイズが動くので全部が再描画される。

## 再現性

figure の寸法は `fig.toml` だけでなく環境にも依存する。マージンは `get_tightbbox()` から実測しており、その戻り値は matplotlib が選んだ目盛りの位置と解決されたフォントに依存する。`pixi.lock` をコミットしているので、クローンすれば figure の確認に使ったバージョンに解決される。環境を固定すれば出力は実行間でバイト単位で一致する。
